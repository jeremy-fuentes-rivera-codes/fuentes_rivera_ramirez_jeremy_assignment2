# Adventure Game Plan: Tech Career Simulator
This tech career simulator is going to diverge into three tech roles that are popular today. Each roles presents two decision pathways, which later reconverge at key story milestones. In total, the game features two major reconvergence points that lead to a unified finaly legacy ending.

## Structure
1. The user is going to be presented with three career paths: Full Stack, Data Analyst and DevOps

2. Regardless of the chosen path, the user will face a problem. This problems will have two unique solution on each of the careers paths chosen.

3. The solution for these problems will lead to a reconverge point called "Career Success".

4. After this, there will be a "Retire" path which will lead the user to two options: becoming a volunteer teacher for people in need, or traveling the world.

5. Regardless of the chosen path, the story will reconverge to a point called "Legacy". At this stage, a message will be displayed congratulating the user on building a successful career and leaving a lasting legacy for future generations.

# Layout and design
The webpage is going to be quite simple. It will feel like a quiz with buttons as quizzes have questions, buttons, and follow-up questions. It will work in much the same way. However, it will be different because each question provides situational text that guides the user through an adventure where they have to choose the best path. To make the adventure more appealing, I will add a congratulation photo at the end of the game to make users feel happier with their outcome. The background will be dark blue and the buttons will be white to assist people with color blindness.
